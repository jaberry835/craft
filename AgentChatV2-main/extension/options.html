Security Package Assist

Extension options

Backend

Root URL of your AgentChatV2 backend — no trailing /api.

Agents

Pick the orchestrator that owns the security-package prompt and MCP tools. Requires the backend URL and auth settings below.
Hold Ctrl / ⌘ to select multiple. When any are selected, the extension runs your primary agent as an orchestrator that consults these specialists (Magentic pattern). Leave empty to call the primary agent on its own.

Authentication

Whatever scope your backend's token validator expects. Defaults to openid profile offline_access.
Use https://login.microsoftonline.us for Azure Government, or https://login.microsoftonline.com for commercial. Defaults to commercial.
If set, the extension skips OAuth and uses this token directly. Clear for production.
