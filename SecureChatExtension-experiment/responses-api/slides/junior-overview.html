Junior — AI Coding Assistant
for Secure Enterprises

Bring agentic AI coding to air-gapped, regulated, and restricted environments. Junior runs inside VS Code with two agent engines, built-in Spec-Driven Development support, and full control over your own AI infrastructure.

🔒

Your Infrastructure

Connects to your Azure OpenAI or APIM gateway. API keys stored in VS Code SecretStorage. Zero telemetry to third parties.

🤖

Choose Your Engine

Two agent engines in one extension — a built-in Local Agent and Copilot CLI (BYOK) — both calling your Azure OpenAI endpoints. One dropdown to switch.

✈️

Offline-Capable

No external SDK or npm dependency at runtime. A single VSIX installs anywhere — air-gapped labs, classified networks, field laptops.

🔌

Extensible via MCP

Connect external tools through the Model Context Protocol. stdio and HTTP transports supported — any MCP server just works.
