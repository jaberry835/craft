# Joke Ratings

This file rates the jokes from `jokes.md` using a custom Funny Meter.

## Funny Meter methodology

Each joke is rated out of 10 using 5 factors, each worth up to 2 points:

1. Wordplay: how clever the pun or language twist is
2. Surprise: whether the punchline feels fresh or predictable
3. Clarity: how quickly the joke is understandable
4. Audience fit: how well it lands for a tech/programming audience
5. Punch strength: whether it gets a laugh, grin, or just mild recognition

### Scale

- 9–10 = excellent, clever, very memorable
- 7–8.9 = strong joke, definitely lands
- 5–6.9 = decent, more smile than laugh
- Below 5 = weak or too flat
