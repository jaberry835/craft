# AAA logo options

Four candidate marks for AAA (A&A Accelerator). Open [`index.html`](./index.html) in a browser, or look at [`overview.png`](./overview.png), to compare them side by side.

| # | Option | Idea |
|---|--------|------|
| 1 | [Shield check](./1-shield-check/) | Shield holding a bold "A", plus a teal approval badge: security and sign-off. |
| 2 | [Ascent](./2-ascent/) | Three rising chevrons in an app tile: A·A·A and "accelerate". |
| 3 | [Prism](./3-prism/) | Three overlapping translucent A-forms in violet, indigo and teal. |
| 4 | [Keystone](./4-keystone/) | A solid "A" with a keyhole crossbar: access control and authorization. |

Each folder contains:

- `mark.svg`: the icon on its own (64 × 64). Prism also has `mark-dark.svg` for dark backgrounds.
- `lockup-light.svg` / `lockup-dark.svg`: the icon with the "AAA · A&A Accelerator" wordmark.
- `favicon.svg`: a simplified version tuned for 16–32 px.
- `preview.html` / `preview.png`: the option on light and dark, as the lockup, and at favicon sizes.

All marks use the app's violet accent (`#6350c5`). The wordmark text uses Segoe UI and is not converted to outlines.
