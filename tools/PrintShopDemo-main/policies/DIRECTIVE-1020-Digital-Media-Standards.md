# DIRECTIVE 1020 — Digital Media Production Standards

**Issuing Authority:** Print & Digital Media Center (PDMC), Administrative Services Division
**Effective Date:** October 1, 2024
**Last Revised:** February 3, 2026
**Reference:** Directive 1000, Section 5

---

## 1. Purpose

This directive establishes the technical specifications, dimension requirements, format standards, accessibility mandates, and production requirements for all digital media products created by or on behalf of the Federal Consolidated Agency (FCA). Digital media products must comply with federal accessibility standards, information security requirements, and agency branding guidelines.

## 2. Scope

This directive applies to all digital media sub-types processed by the PDMC:
- Graphics & Illustrations
- Logo Design
- Social Media Assets
- Web Banners & Headers
- Email Templates
- Presentation Design
- Infographics
- Video & Motion Graphics

---

## 3. Graphics & Illustrations

### 3.1 Authorized Dimensions and Formats

| Use Case | Dimensions (pixels) | File Format | Color Space |
|----------|---------------------|------------|-------------|
| General Purpose (web) | 1200 × 800 to 2400 × 1600 | PNG, SVG | sRGB |
| General Purpose (print) | As needed | TIFF, EPS, PDF | CMYK |
| Icon / Badge | 512 × 512 (max) | SVG, PNG | sRGB |
| Illustration (full page) | 2550 × 3300 (8.5"×11" at 300 DPI) | TIFF, PSD, PDF | CMYK |
| Infographic Element | 800 × 800 to 1200 × 1200 | PNG, SVG | sRGB |

3.1.1 Raster graphics (PNG, TIFF, JPEG) must be delivered at a **minimum resolution of 150 DPI** for web use and **300 DPI** for any product that may be printed.

3.1.2 Vector graphics (SVG, AI, EPS) are preferred for logos, icons, and illustrations that may be scaled across multiple formats.

3.1.3 Graphics exceeding 10 MB per file must be flagged in the request. Files exceeding 50 MB require delivery via the PDMC secure file transfer system rather than email.

### 3.2 Content Requirements

The request description for graphics **must** include:
- (a) The intended use context (web page, report, presentation, social media, print collateral)
- (b) Desired dimensions in pixels (for digital) or inches with DPI (for print-ready)
- (c) A detailed description of the desired graphic content, including:
  - Subject matter and key visual elements
  - Text or labels to appear within the graphic
  - Color preferences (must reference approved brand palette per Directive 925)
  - Mood or style references (e.g., "professional," "infographic-style," "illustrated")
- (d) Background preference (transparent, white, colored, or photographic)
- (e) Accessibility requirements — all graphics containing text must include alt-text descriptions per Section 508

### 3.3 Restrictions

3.3.1 Graphics may not incorporate copyrighted imagery, clip art from unauthorized sources, or AI-generated imagery without review and approval by the Public Affairs Office.

3.3.2 Photographs of identifiable personnel require a signed Model Release form (FCA-773) on file before inclusion in any graphic asset. For photographs of personnel in classified programs, see Directive 1200, Section 9.

3.3.3 Graphics depicting agency facilities, equipment, or operations in a way that could reveal security-sensitive information must be reviewed by the Security Directorate prior to production.

## 4. Logo Design

### 4.1 Authorization Requirements

4.1.1 Creation of **new logos** for any FCA organizational element, program, project, event, or initiative **requires** prior approval from the Public Affairs Office (PAO) and the Brand Standards Board (BSB).

4.1.2 Logo design requests must include BSB Pre-Approval Reference Number in the request description. Requests without this reference will be returned without action.

4.1.3 The BSB meets on the first and third Wednesday of each month. Requestors should plan for a minimum 30-day lead time for logo approval.

### 4.2 Design Standards

4.2.1 All new logos must be designed in the following mandatory deliverable formats:

| Format | Specification | Purpose |
|--------|--------------|---------|
| SVG | Scalable, outlined fonts | Web, digital applications |
| AI | Adobe Illustrator, editable | Source file for future modifications |
| PNG (transparent) | 1024 × 1024, 2048 × 2048, 4096 × 4096 | General digital use |
| PNG (on white) | Same as above | Documents, presentations |
| EPS | Vector, outlined fonts | Print production |
| Favicon set | 16 × 16, 32 × 32, 180 × 180 | Web browser icons (if applicable) |

4.2.2 Every logo must be designed with the following variations:
- Full color (primary)
- Reversed (white on dark background)
- Grayscale
- Single-color black

4.2.3 Logos must maintain legibility at a minimum reproduction size of 0.75 inches wide (print) or 72 pixels wide (digital).

### 4.3 Content Requirements

The request description for logo design **must** include:
- (a) The BSB Pre-Approval Reference Number
- (b) The name of the organization, program, or initiative
- (c) The intended applications for the logo (letterhead, web, signage, merchandise, etc.)
- (d) Any mandatory elements (e.g., parent organization logo must appear)
- (e) Preferred style direction and any reference logos for inspiration
- (f) Text to be incorporated (if any) — fonts must be selected from the approved agency font library
- (g) Whether a mascot, symbol, or wordmark approach is desired

### 4.4 Restrictions

4.4.1 Logos may not incorporate the Great Seal of the United States, the FCA Agency Seal, or any other protected government insignia without explicit legal counsel approval.

4.4.2 Logos may not use commercially licensed fonts unless the agency holds an enterprise license. The approved font library includes: Inter, Source Sans Pro, Merriweather, Roboto, and Noto Sans.

4.4.3 Unofficial logos, "morale" patches, or unit insignia are **not** produced by the PDMC. These must be procured through personal funds and may not use the agency name or seal.

## 5. Social Media Assets

### 5.1 Authorized Dimensions

| Platform | Asset Type | Dimensions (pixels) | Aspect Ratio |
|----------|-----------|---------------------|-------------|
| X (Twitter) | Post Image | 1200 × 675 | 16:9 |
| X (Twitter) | Header | 1500 × 500 | 3:1 |
| Facebook | Post Image | 1200 × 630 | 1.91:1 |
| Facebook | Cover Photo | 820 × 312 | 2.63:1 |
| Facebook | Event Cover | 1920 × 1080 | 16:9 |
| Instagram | Square Post | 1080 × 1080 | 1:1 |
| Instagram | Story/Reel | 1080 × 1920 | 9:16 |
| Instagram | Carousel | 1080 × 1080 | 1:1 |
| LinkedIn | Post Image | 1200 × 627 | 1.91:1 |
| LinkedIn | Cover Photo | 1584 × 396 | 4:1 |
| YouTube | Thumbnail | 1280 × 720 | 16:9 |
| YouTube | Channel Banner | 2560 × 1440 | 16:9 |

5.1.1 Social media assets **must** be created in the exact dimensions specified above. Custom dimensions for social media platforms are not authorized.

5.1.2 All social media assets must include the agency logo or wordmark in compliance with Directive 925. Logo placement must follow the approved social media brand guide.

### 5.2 Content Requirements

The request description for social media assets **must** include:
- (a) The specific platform(s) and asset type(s) needed
- (b) The exact post text or caption (for context — not included in the graphic unless specified)
- (c) The planned publish date(s) — PDMC requires minimum 5 business days for social media graphics
- (d) All text to appear within the graphic (headlines, calls-to-action, dates, URLs)
- (e) Campaign name or hashtag (if part of an ongoing campaign)
- (f) Whether the post requires PAO approval (all external-facing social posts require PAO clearance)

### 5.3 Restrictions

5.3.1 **Only the PAO Social Media Team** may post content to official FCA social media accounts. The PDMC produces the creative assets; all posting and scheduling is managed by PAO.

5.3.2 Social media assets may contain **only information classified as Unclassified / Public**. No FOUO, CUI, or Super Classified content may appear in social media assets under any circumstances.

5.3.3 Social media graphics may not include:
- Photographs of minors without parental consent (Form FCA-774)
- Images of security infrastructure, access control points, or secure areas
- Personal contact information of any individual
- Endorsements of political candidates, parties, or positions
- Commercial product endorsements or brand logos (other than FCA's own)

## 6. Web Banners & Headers

### 6.1 Authorized Dimensions

| Asset Type | Dimensions (pixels) | File Size Limit | Format |
|-----------|---------------------|----------------|--------|
| Homepage Hero Banner | 1920 × 600 | 500 KB | JPEG, WebP |
| Interior Page Banner | 1920 × 300 | 300 KB | JPEG, WebP |
| Sidebar Banner | 300 × 250 | 150 KB | PNG, JPEG |
| Leaderboard Banner | 728 × 90 | 100 KB | PNG, JPEG |
| Mobile Banner | 640 × 200 | 200 KB | JPEG, WebP |
| Announcement Bar | 1920 × 80 | 80 KB | PNG |

6.1.1 Web banners must be optimized for web performance. Files exceeding the size limits above will be rejected.

6.1.2 All web banners must be delivered in both standard (1x) and retina (2x) resolutions.

### 6.2 Accessibility Requirements

6.2.1 In accordance with Section 508 of the Rehabilitation Act, all web graphics must:
- Include a descriptive alt-text tag (provided by the requestor in the description)
- Maintain a minimum contrast ratio of 4.5:1 for text against background
- Not rely solely on color to convey information
- Not contain flashing or strobing elements

6.2.2 The PDMC will perform an automated accessibility check on all web assets. Products failing the check will be revised before delivery.

### 6.3 Content Requirements

The request description **must** include:
- (a) The specific web page URL where the banner will be displayed
- (b) Alt-text description for accessibility compliance
- (c) All text content for the banner
- (d) Whether the banner is a link (and the destination URL)
- (e) Responsive behavior requirements (does the banner need to adapt to mobile?)

## 7. Email Templates

### 7.1 Authorized Specifications

| Parameter | Requirement |
|-----------|------------|
| Width | 600 pixels (maximum rendering width) |
| Format | HTML with inline CSS (no external stylesheets) |
| Image Width | Maximum 580 pixels (within 10px padding) |
| Total Email Size | Under 100 KB (HTML + inline images) |
| External Images | Hosted on agency CDN; no third-party hosts |
| Fonts | System-safe fonts only: Arial, Helvetica, Georgia, Times New Roman |

7.1.1 Email templates must render correctly in the following email clients: Microsoft Outlook (2019+, M365), Apple Mail, Gmail, and Outlook Web Access.

7.1.2 All email templates must include a plain-text fallback version.

### 7.2 Content Requirements

The request description **must** include:
- (a) The type of email (newsletter, announcement, event invitation, operational update)
- (b) Whether this is a new template or a modification of an existing template (include template ID)
- (c) Complete content in final form — all headlines, body text, and calls-to-action
- (d) Recipient audience (internal, inter-agency, public)
- (e) Planned send date and frequency (for recurring templates)
- (f) Whether the email will be sent through the agency mass distribution system (requires IT Security review)

### 7.3 Restrictions

7.3.1 Email templates for mass distribution (100+ recipients) require IT Security Office review for phishing prevention compliance. The IT Security approval number must be included in the request.

7.3.2 Email templates may not include executable attachments, JavaScript, or embedded forms. Links to secure agency forms are permitted.

## 8. Presentation Design

### 8.1 Authorized Specifications

| Parameter | Standard | Widescreen |
|-----------|----------|-----------|
| Slide Size | 10" × 7.5" (4:3) | 13.333" × 7.5" (16:9) |
| Format | PowerPoint (.pptx) | PowerPoint (.pptx) |
| Max Slides | 60 per engagement | 100 per engagement |
| File Size | Under 50 MB | Under 100 MB |
| Fonts | Approved font library only | Approved font library only |
| Master Slide | Must use FCA-approved template | Must use FCA-approved template |

8.1.1 Presentations must be designed using the current FCA PowerPoint master template. Custom templates are not authorized unless approved by the BSB.

8.1.2 Presentations exceeding 60 slides (standard) or 100 slides (widescreen) require Director-level justification and are charged at a premium rate.

### 8.2 Content Requirements

The request description **must** include:
- (a) The presentation purpose (briefing, training, conference, public event)
- (b) The audience (internal leadership, all-hands, external stakeholders, public)
- (c) Desired slide ratio (4:3 or 16:9)
- (d) Complete content outline or final text for each slide — the PDMC designs layouts but does not write content
- (e) Any data visualizations required (charts, graphs, diagrams) with source data provided
- (f) Speaker notes requirements (if applicable)
- (g) Whether the presentation will be printed as handouts (affects design approach)

### 8.3 Restrictions

8.3.1 Presentations containing FOUO or higher classified content must not include agency organizational charts below the Directorate level.

8.3.2 Presentations for external audiences must receive PAO clearance before delivery.

## 9. Infographics

### 9.1 Authorized Dimensions

| Type | Dimensions (pixels) | Print Equivalent |
|------|---------------------|-----------------|
| Standard (vertical) | 1200 × 3000 (max) | 8" × 20" at 150 DPI |
| Wide (horizontal) | 2400 × 1200 (max) | 16" × 8" at 150 DPI |
| Social-optimized | 1080 × 1080 | Square for Instagram/LinkedIn |
| Poster-sized | 2400 × 3600 | 24" × 36" at 100 DPI |

9.1.1 Infographics exceeding 3000 pixels in height should be segmented into logical sections that can function independently when shared.

### 9.2 Content Requirements

The request description **must** include:
- (a) The topic and key message of the infographic
- (b) All data points, statistics, and facts to be represented (with sources cited)
- (c) Data source attribution — all statistics must include the source name and date
- (d) Desired visual approach (data-driven, process-flow, comparison, timeline, geographic)
- (e) Whether the infographic will be posted online (requires Section 508 accessible version)
- (f) Target audience and distribution method

### 9.3 Data Accuracy

9.3.1 The PDMC **does not** verify the accuracy of data provided by requestors. The requestor is solely responsible for ensuring all statistics, figures, and claims are accurate and properly sourced.

9.3.2 Infographics published on external-facing platforms must include a citation section or "Sources" footer.

## 10. Video & Motion Graphics

### 10.1 Authorized Specifications

| Parameter | Standard | Premium |
|-----------|----------|---------|
| Resolution | 1920 × 1080 (1080p) | 3840 × 2160 (4K) |
| Frame Rate | 30 fps | 24 or 30 fps |
| Duration | Up to 60 seconds | Up to 3 minutes |
| Format | MP4 (H.264) | MP4 (H.265) or ProRes |
| Audio | Optional background music | Licensed music, voiceover |
| Deliverables | Final rendered file | Final + project files |

10.1.1 Video production exceeding 3 minutes in duration is classified as **Full Video Production** and must be coordinated through the PAO Visual Communications Branch, not through the PDMC.

10.1.2 All motion graphics must include closed captions compliant with Section 508 accessibility standards.

### 10.2 Content Requirements

The request description **must** include:
- (a) Video purpose and intended audience
- (b) A storyboard or shot-by-shot description
- (c) All text overlays, titles, and lower-thirds content
- (d) Whether voiceover narration is required (requestor must provide the voiceover script and audio file; PDMC does not record voiceovers)
- (e) Background music preference (PDMC maintains a library of royalty-free tracks)
- (f) Duration target
- (g) Platform(s) where the video will be published

### 10.3 Restrictions

10.3.1 Videos intended for public release (websites, social media, media outlets) require PAO final review and approval before delivery.

10.3.2 Videos may not contain classified information at any level above Unclassified.

10.3.3 Videos featuring identifiable personnel require individual Model Release forms (FCA-773) for all appearing individuals.

## 11. General Digital Media Rules

### 11.1 File Naming Convention

All delivered digital assets must follow the FCA naming convention:
```
[OrgCode]_[ProjectName]_[AssetType]_[Dimensions]_[Version].[ext]
```
Example: `OPA_SafetyCampaign_SocialIG_1080x1080_v2.png`

### 11.2 Color Management

11.2.1 All digital assets intended for screen display must use the sRGB color space.

11.2.2 All digital assets intended for print must use the CMYK color space (FOGRA39 or GRACoL 2006 profile).

11.2.3 Brand colors must be applied using the exact hex values specified in Directive 925:
- Agency Blue: #1B3A5C
- Agency Gray: #4A5568
- Agency Gold: #D4A843
- Agency Green: #2D6A4F
- Alert Red: #C53030 (restricted use)

### 11.3 Intellectual Property

11.3.1 All digital assets produced by the PDMC are the property of the Federal Consolidated Agency and are not subject to copyright protection under 17 U.S.C. § 105.

11.3.2 Third-party content (stock photos, fonts, music) used in digital assets must be properly licensed. The PDMC maintains licenses for approved stock libraries; requestors may not provide content from unauthorized sources.
