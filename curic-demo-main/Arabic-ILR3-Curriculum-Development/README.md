# Arabic ILR-3 Curriculum Development Structure

## Program Profile
- Language: Arabic
- Target Proficiency: ILR-3
- Duration: 6 months
- Focus Areas: Technology Policy, Economics, Public Health

## Purpose
This workspace is organized for end-to-end curriculum development, from analysis and framework design through unit planning, materials production, assessment, and revision.

## Top-Level Artifact Areas
- `00-Program-Management/`: project charter, timelines, staffing, and review cadence.
- `01-Needs-Analysis/`: audience analysis, task analysis, domain research, and constraints.
- `02-Proficiency-Framework/`: ILR-3 performance descriptors, can-do statements, and language targets.
- `03-Syllabus-and-Scope-Sequence/`: syllabus, sequencing, thematic map, and pacing.
- `04-Unit-Plans/`: six monthly unit plans aligned to the 6-month duration.
- `05-Lesson-Plans/`: lesson-level planning folders by month.
- `06-Student-Materials/`: readings, glossaries, discussion packets, and handouts.
- `07-Instructor-Guides/`: facilitation notes, answer keys, and model responses.
- `08-Assessments/`: diagnostic, formative, midpoint, capstone, and rubrics.
- `09-Practical-Exercises/`: simulations, role plays, and analytic writing tasks.
- `10-Language-Resources/`: terminology, source texts, transcripts, and annotations.
- `11-Media/`: audio, slides, and visual assets.
- `12-QA-and-Revision/`: review notes, pilot feedback, and revision logs.
- `13-Templates/`: reusable curriculum-development templates.
